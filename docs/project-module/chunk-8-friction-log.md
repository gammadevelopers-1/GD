# Chunk 8 — Friction log

Fill this in **the same day** something happens. A log written from memory at
the end of the week records opinions; one written as you go records facts.

Anyone on the pilot adds rows. No row is too small — "I could not remember which
tab the repo link was on" is exactly the kind of thing this is for.

## How to classify

| Type | Meaning | Where it goes |
| --- | --- | --- |
| **Defect** | Prevents normal use, contradicts the permission contract, or shows something wrong | Fixed inside Chunk 8 |
| **Permission** | Anyone saw, or could reach, something they should not | Stop the line. Fix and re-test before anything else |
| **Confusion** | It works, but somebody had to be told how | Usually a wording or layout fix — decide case by case |
| **Request** | Would be nice, or is a habit from another tool | Post-launch backlog, untouched |
